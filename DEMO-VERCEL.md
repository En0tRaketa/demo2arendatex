# Статическое демо «ТехАренды»: публикация

`techarenda-static-demo.zip` — отдельная демо-версия для показа клиентам:

- **Как устроено.** Обычные HTML, CSS и JS. Без PHP, MySQL, сервера и внешних API.
- **Дизайн.** Собрано из тех же шаблонов, что и рабочий сайт, поэтому выглядит так же: тексты, стили, иллюстрации, меню, анимации.
- **Калькулятор.** Работает в браузере. Расчёт подписан как демонстрационный.
- **Форма заявки.** Проверяет поля. По кнопке «Отправить заявку» показывает уведомление
  «Демонстрационный режим: отправка заявки отключена». Ничего никуда не отправляется:
  - в коде нет адреса API;
  - политика безопасности запрещает сетевые запросы (`connect-src 'none'`).
- **Чего в демо нет.** Админки, токенов, паролей, реальных ключей и рабочей конфигурации.
- **Поисковики.** Закрыто от индексации тремя способами:
  - `<meta name="robots" content="noindex, nofollow">`;
  - заголовок `X-Robots-Tag` (файлы `vercel.json` и `_headers`);
  - `robots.txt` с `Disallow: /`.

Содержимое архива:

```
index.html  privacy.html  robots.txt  favicon.svg
vercel.json   ← заголовки для Vercel
_headers      ← те же заголовки для Netlify / Cloudflare Pages
assets/ (css, js, fonts)   images/ (иллюстрации)
```

## Где можно публиковать: условия хостингов (проверено 18.10.2026)

Демо рекламирует продукт, который вы продаёте. Такое использование хостинги считают **коммерческим**.

| Хостинг | Бесплатный тариф для коммерческого демо | Что сказано |
|---|---|---|
| **Vercel Hobby** | ❌ нельзя | «Hobby teams are restricted to non-commercial personal use only». К коммерческому использованию прямо отнесена «реклама продажи товара или услуги» и оплата за создание сайта ([Fair Use Guidelines](https://vercel.com/docs/limits/fair-use-guidelines)) |
| **Vercel Pro** | ✅ можно | платный тариф (около $20 в месяц за участника; оплата нужна картой, принимаемой Vercel) |
| **Netlify (бесплатный)** | ✅ по ответам Netlify | на форуме Netlify подтверждали в 2021, 2024 и мае 2025: «You are welcome to use the free tier for commercial purpose». Запрещена только перепродажа хостинга ([обсуждение](https://answers.netlify.com/t/can-we-use-netlify-free-plan-for-commercial-purposes/41545)) |
| **Cloudflare Pages** | вероятно ✅ | ограничения «только некоммерческое» я в условиях не нашёл, но первоисточник не проверял. Перед использованием прочитайте актуальные условия |

**Рекомендация:** бесплатно — **Netlify**. Если нужен именно Vercel — тариф **Pro**.
Условия хостингов меняются, перед публикацией перечитайте их.

**Доступность из России.** На форуме Vercel есть сообщения 2025 года о блокировке IP-адресов Vercel у российских операторов,
в том числе мобильных ([пример](https://community.vercel.com/t/urgent-production-domain-bbqp-pro-is-blocked-in-russia-confirmed-vercel-ip-issue/29141)).
Перед показом клиенту откройте демо с мобильного интернета нескольких операторов.
Самый надёжный вариант для российской аудитории — положить демо на тот же REG.RU, например на поддомен `demo.ваш-домен.ru`.
Это обычные статические файлы, PHP для них не нужен.

## Вариант 1. Netlify (бесплатно, без командной строки)

1. Распакуйте `techarenda-static-demo.zip`.
2. Зарегистрируйтесь на netlify.com.
3. Откройте **app.netlify.com/drop** и перетащите **папку** с файлами демо в окно браузера.
4. Через несколько секунд появится адрес вида `https://имя.netlify.app`. Имя можно сменить:
   Site configuration → Change site name.
5. Файл `_headers` применится автоматически: noindex и заголовки безопасности.

## Вариант 2. Vercel (тариф Pro для коммерческого показа)

**Через сайт.** Загрузите папку демо в репозиторий GitHub, затем в Vercel:
- Add New → Project → Import → выберите репозиторий;
- Framework Preset: **Other**;
- Build Command — пусто, Output Directory — `.` (корень);
- нажмите Deploy.

**Через командную строку** (нужен Node.js на вашем компьютере):

```powershell
cd путь\к\демо
npx vercel@latest deploy --prod
```

Файл `vercel.json` добавит noindex и заголовки безопасности.

## Вариант 3. REG.RU или любой обычный хостинг

Загрузите содержимое папки в корень поддомена (например `demo.ваш-домен.ru`).
Для Apache noindex и так указан в HTML и `robots.txt`.
По желанию добавьте в `.htaccess` строку `Header set X-Robots-Tag "noindex, nofollow"`.

## Проверка после публикации

1. Страница открывается, все картинки на месте, вверху плашка «Демо-версия: заявки не отправляются».
2. Кнопка «Оставить заявку» в карточке переносит к калькулятору. Цена меняется при изменении часов и доставки.
3. После заполнения формы кнопка показывает уведомление о демо-режиме, а не «заявка отправлена».
4. На телефоне нет горизонтальной прокрутки.
5. Исходный код страницы (Ctrl+U) содержит `noindex, nofollow`.

Как пересобрать демо после изменения текстов или цен: `php tools/build-demo.php <папка>` из исходников
(архив `techarenda-source.zip`, папка `tools/`). Демо собирается из стартового контента `app/seed.php`.
